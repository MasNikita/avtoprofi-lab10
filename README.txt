Лабораторная работа №10 — «АвтоПрофи»

Файлы:
  index.html   — разметка Landing Page
  styles.css   — стили и адаптивная вёрстка
  script.js    — кнопки, форма, события аналитики
  assets/avto-hero.webp — изображение автомобиля из материалов проекта

Запуск: откройте index.html двойным щелчком или через Live Server в VS Code.

Назначение: учебная целевая страница автосалона. Категории не являются
реальными предложениями. Заявка не отправляется: её данные временно
сохраняются только в sessionStorage браузера.

Подключение веб-аналитики:
  1. Создайте собственный счётчик Яндекс Метрики и ресурс GA4.
  2. В script.js замените null и пустую строку в ANALYTICS на свои ID.
  3. При необходимости настройте в Метрике цели с идентификаторами:
     cta_click, car_select, form_start, form_submit.
  4. Опубликуйте папку на GitHub Pages и протестируйте события.

ВНИМАНИЕ: фактическая публикация сайта и подключение счётчиков
не выполнялись. До создания собственных счётчиков сайт показывает
события в консоли браузера (F12), не отправляя аналитику наружу.
